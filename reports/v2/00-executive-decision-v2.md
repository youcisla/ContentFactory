## Recommendation in one paragraph

Build the production spine from **SVG frames generated by Python → rasterised by a small deterministic renderer → encoded by the already-installed FFmpeg**, with `libass`/`drawtext` for captions and Quick Sync (`h264_qsv`) available for fast encoding. Use **Manim only for mathematical/technical diagrams** if the topic demands them. Use **remote Blender on a rented GPU ($0.11–0.27/h) only for short 3D hero shots**, never for full episodes. Publishing goes through the **YouTube Data API directly**, manual for the first ten uploads. TTS: **Chatterbox-Turbo locally** (MIT, CPU-targeted) or **Kokoro-82M** (Apache-2.0) as fallback; licensed cloud TTS only if quality proves insufficient.
